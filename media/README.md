# Marketplace media

This folder is packaged with the extension (see `package.json#files`) and is intended for screenshots/GIFs referenced from `README.md`.

Suggested filenames (already referenced by default in `README.md`):

- `termetrix-hero.gif` (or `.png`)
- `termetrix-loc.gif` (or `.png`)

Tip: keep paths stable so the Marketplace renders correctly.
